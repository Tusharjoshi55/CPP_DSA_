        Protected :- variable(data) and method are accessible to class and it's drived class.  //inheritance topic.
                    // we can use getter and setter function to modifes the Protected Modifiers.

3. Encapsulation
        It is wrapping up of data(veriables) and method(member function) in a single unit called Class.
        It is used in data hiding using access Modifiers. use private
        for eg.

        //normal function
        void helloWorld(){
            cout<<"Hello, World !";
        }
        int main(){
            helloWorld();
            return 0;
        }

        //Encapsulation :- wrapping data and method inside a class
        class Print{
            private:
            void helloWorld(){
                cout<<"Hello, World !";
            } 
        }

        int main(){
            Print obj;
            //now we can not use this function because it is hidden inside a wrapper or it's abstracted
            obj.helloWorld();
            return 0;
        }


4.Constructor

        Special function invoked automatically at the time of object creation. Used for initilization
        -Same name as class name
        -Constructor dosen't have return type
        -Only calls once(automatically), at object creation.
        -Memory allocation is happen when constructor is called
        -if we not defined a constructor cpp automatically create one for class

            types of constructor

                    a. Non-parameterized constructor
                    eg. class ClassName{
                        void ClassName();
                    }


                    b. parameterized constructor

                    eg.
                    class ClassName{
                        void ClassName(int var){
                            //body
                        }
                    };
                    int main(){
                        ClassName obj(value);
                    }


                *important
                Constructor overloading(Polymorphism) - means same constructor name but differnt parameter.
                eg.
                class ClassName{
                    void ClassName(){
                        //body
                    }
                    void ClassName(int var){
                        //body
                    }
                };
                int main(){
                    ClassName obj1; // first constructor called
                    ClassName obj2(value); //Second Constructor called

                }


                *important
                this keyword- this is a Special pointer in cpp that points to the current object.
                this->prop is same *(this).prop



                c. Copy Constructor :- Special constructor(defalut) used to copy  properties of one object into another.

                when copy constructor are created they are copy of the main objet to other object.
                So, there is the type of Copy.

                **important
                a. Shallow Copy :-A shallow copy of an object copies all the member values from one object to another. //defaul is shallow copy

6.Inheritance - when we create a drive class(child class) that have properties of base class(parent class).
         syntex : 
         class Base{
            //body of Base class
         };
         class Drived : access_modifier Base{
            //body of Drived class
            void functin(var1) : void BaseFunction(var2, var3){   // calling the parent class method
                this->var1 = var1;
            }
         };

         ** Order of Execution - Base Class constructor then Drived class constructor. when we create the object of drived class //with programm


         ** Important Acces Modifiers
                            Drived Class            Drived Class         Drived Class
         Base Class         private mdoe            Protected mode       public mode  

         Private            not inherited           not inherited        not inherited
         Protected          private                 Protected            Protected
         Public             private                 Protected            public


        Type of Inheritance
        a. Single level Inheritance - base class to derived class
        b. Multi-level Inheritance - one base class one derived class that drive class is the base class for other derived class
        c. Multiple Inheritance - one or more base class has one derived class. Multiple class seperated by comma in syntex.
        d. Hierarchial Inheritance - one base class has multiple derived class like binary tree.
        e. Hybrid Inheritance - when we merge one and another type of inheritance together.
